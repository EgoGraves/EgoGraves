Coby Fragoso · EgoGraves Studio

Independent developer in Northern California. I design and direct; Claude writes the code.

Most of my work runs on a loop I call the design chair. A Claude chat plans the work and writes plain-language briefs, a builder implements them, and a separate pass audits the result before anything ships. The tests are written before the build, and they have to be able to fail. Mistakes get logged, including the AI's, and each one becomes a rule.
